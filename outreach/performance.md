# Performance

Written by `/email-learn`, keyed by bracket and opener mechanism. Bracket-level
counts only - no names, no addresses. This file is tracked.

**Under about 12 sends per opener mechanism this is directional, not
significant.** Say so every time it is read. Never drop a bracket on one batch.

```
batch      bracket  opener                  sent  replied  calls
```

## Watch for

- A bracket with a low reply rate but a high call rate among those who do reply.
  Worth more than it looks, and the raw reply rate says the opposite.
- An opener that gets replies but no calls: the hook is landing and the ask is not.
- Bounces clustered in one bracket - usually a stale list, not a bad email.
