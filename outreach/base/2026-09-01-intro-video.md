I'm a civil and environmental engineer from Ireland, living in Christchurch, New Zealand, with a Master's in Renewable and Sustainable Engineering. I'm currently developing Terrain Flow Design (TerrainFlow in the QGIS plugin repository), a free and open-source QGIS plugin for designing and validating water-harvesting earthworks such as swales, basins, dams, berms and diversion drains.

I started building this tool after volunteering on a rewilding project that lost several years of plantings to drought. Standing on that site, it made me want to test whether some simple earthworks could have captured enough rainfall to change the outcome. Most land managers have no easy way to run that test before committing time and money to digging. I use QGIS professionally, and wanted them to have an easy-to-use tool to do just that.

    The Tool
End to end, it lets you:
    1. Run a rainfall flow analysis on topographic data — public LiDAR where it exists, or coarser open elevation data anywhere it doesn't
    2. Use in-built tools to identify suitable earthwork locations
    3. Draw earthworks in, with accurate dimensions and depths
    4. Instantly receive feedback on earthwork sizing, and on how overflow cascades from one structure to the next
    5. Re-run the flow analysis to see how the design performs before anything is built

    Validation
I've tested the tool against CAMELS-NZ, a dataset published specifically to validate hydrological models against real measurements. On a catchment with 34 years of measured flow, both the catchment area it delineates and the runoff it predicts came within a couple of percent of the published figures. Its flow analysis also matches WhiteboxTools, a widely used open-source hydrology package, almost cell for cell. That's one catchment so far, with more to be tested before release.
